摘要

多模态神经算子试图把密集场观测与稀疏传感器测量结合起来，同时保留神经算子在任意坐标上推理的能力。本文以一维黏性 Burgers 方程为对象，研究这一目标在当前项目中能够被证据支持到什么程度。模型先把初始场编码为卷积 token 和低维潜变量，在潜空间积分时间演化，再通过交叉注意力解码任意时空查询。传感器读数被投影到同一 token 空间，并在上下文编码器之前与场 token 拼接。因此，当前实现属于“早期 token 拼接加后期查询注意力”的混合融合，而不是理想的纯早期融合或纯晚期融合。

本文报告两组证据。第一，严格周期平移增强把 1,408 条训练轨迹扩展为 4,224 条：对完整时空解沿周期空间方向做循环平移，不改变方程。三个配对随机种子的平均测试相对 L2 从 0.103485 降到 0.097188，相对改善 6.09%，三个种子全部改善，验证集相对 L2 也全部改善。PDE 残差没有一致改善，因此该结果支持“空间覆盖与预测精度提升”，不支持“物理一致性全面提升”。

第二，本文审计两条分别标记为交叉注意力和预融合的存档运行。两份配置完全相同，参数量相同，当前训练入口也没有独立的预融合控制项。两次运行的数值不同，但现有产物无法把差异归因于融合策略。此外，八传感器初步试验差于匹配的纯场参考。因此，本文将直接传感器融合视为负结果，并给出后续比较所需的跨模态对齐损失、模态丢弃、配对随机种子和架构指纹。核心结论保持克制：周期平移增强在测试基准上得到支持，多模态融合收益尚未得到证明。

关键词: 神经算子；多模态学习；传感器融合；Burgers 方程；周期增强；可复现性

1 引言

神经算子学习函数空间之间的映射，可以在推理时以不依赖固定数值网格的方式近似 PDE 解算子 [1-4]。多数神经算子基准假设输入是一个定义良好的场。实际工程系统往往提供多种观测：仿真给出密集初始场，检测系统给出少量测点；气象模型同时接收卫星场和地面站；结构监测系统同时使用全场测量与稀疏传感器网络。

多模态输入带来一个直接问题：不同模态应在何处第一次交互，哪些参数应共享，模型如何区分来自不同物理来源的信息？常见叙事是比较早期特征融合与晚期注意力融合，并期待一种策略在精度上更好、另一种在物理一致性上更好。这个叙事有吸引力，但成立需要独立可辨识的实现、匹配的训练预算、重复随机种子，以及能够隔离融合机制的评测协议。

本文回到项目保存的产物，检查这些主张是否成立。结论比最初叙事更有限。两条带不同融合标签的存档运行确实产生了不同结果，但保存的配置和参数签名不足以证明它们是两条不同的计算图。与此同时，后续的单模态实验提供了更干净的正面结果：严格周期平移在不改变 PDE、分辨率、模型规模和优化预算的前提下，改善了三个配对运行。

本文有四方面贡献。

  1. 把当前多模态算子写成明确的计算图，并指出其融合路径属于混合 token 融合。
  2. 通过三个配对随机种子，建立严格周期平移增强的可重复正面结果。
  3. 审计早期融合对比，在产物不足时把因果表述降级为描述性报告。
  4. 报告传感器融合的初步负结果，并列出证明多模态收益所需的最小控制实验。

本文只讨论一维 Burgers 基准，不宣称一般融合规律、PDE 求解最优性能或工程级替代能力。

2 问题与证据基础

2.1 控制方程

基准求解黏性 Burgers 方程

\[ \frac{\partial u}{\partial t}+u\frac{\partial u}{\partial x} =\nu\frac{\partial^2 u}{\partial x^2}, \qquad x\in[0,1),\quad t\in[0,1], \]

空间采用周期边界。保存的数据场包含 256 个空间点和 101 个时间点。数据覆盖五个黏性系数 (\nu\in{0.004,0.006,0.008,0.01,0.012}) 和五类初始场：Fourier、混合场、弱高频、弱尖峰和弱台阶。学习目标是近似初值到解的算子

\[ \mathcal{G}:u_0(x)\mapsto u(x,t), \]

在多模态情形下近似

\[ \mathcal{G}: \left(u_0(x),\,\{(x_i,t_s,u_i)\}_{i=1}^{N}\right) \mapsto u(x,t). \]

密集模态是初始场；稀疏模态是在固定空间位置和固定时刻 (t_s) 采样的点值。代码支持 (N>0)，但本文证据最完整的结果使用 (N=0)。这个区别很重要：算子主干已经足以支持配对增强研究，传感器分支仍然处于探索阶段。

2.2 数据划分

所有保留的三种子比较使用同一套自建 Burgers 数据。原始课程训练集包含 1,408 条轨迹，验证集 128 条，同分布测试集 128 条。训练集主体是 512 条 Fourier 和 512 条混合场，另有 3 类弱课程场各 128 条。测试集由同五个黏性档位下的 Fourier 与混合场组成。数据目录中另有分布外文件，但本文的配对表只使用保存的同分布测试结果，因此不把 OOD 性能写成已验证结论。

2.3 证据原则

本文只保留能够连接到已保存 metrics.json、检查点签名、训练配置或可执行代码路径的数值结论。连接关系间接时，结论降级为观察；产物与结论矛盾时，删除该结论。

目录名称不能作为架构证据。例如，路径中出现 prefusion 只是标签，不能证明模型执行了独立的预融合计算图。

3 多模态算子结构

3.1 输入输出接口

算子将初始场和可选传感器映射到查询坐标处的值：

\[ \hat{u}(x,t) =G_\theta\left(u_0,\{(x_i,t_s,u_i)\}_{i=1}^{N}\right)(x,t). \]

训练完成后可以在任意坐标查询输出，不要求先生成固定网格。保留实现使用查询解码器。代码中另有网格解码器，但本文实验未使用。

图 1 场编码、潜空间时间演化、传感器 token 融合、上下文编码与查询解码。只有 --sensor-count 大于 0 时传感器路径才启用。

3.2 场编码器

初始场先构造高通表示

\[ h(u_0)=u_0-\operatorname{smooth}_{15}(u_0), \]

网络输入为 ([u_0,0.5h(u_0)])。两层一维 CNN 生成局部特征，自适应平均池化得到 32 个空间 token，并投影到 64 维。同一初始场通过卷积流形自编码器编码为 32 维潜变量 (z_0)。流形信息通过投影加入 token，另一条流形 CNN 分支提供第二组潜变量派生 token。

场编码可写为

\[ T_f=\operatorname{CNN}([u_0,0.5h(u_0)]), \qquad z_0=\operatorname{Enc}_{\mathrm{manifold}}(u_0), \qquad C_f=\Phi_f(T_f,z_0). \]

流形编码器在算子目标优化前单独预训练。保留运行使用 1,500 步预训练。

3.3 潜空间时间演化

潜变量通过学习到的向量场演化：

\[ \frac{dz}{dt}=v_\theta(z), \qquad z(t)=z_0+\int_0^t v_\theta(z(s))\,ds. \]

实现采用 4 步显式 Euler 积分。这是一个紧凑的连续时间先验，不是高精度 ODE 求解器。它让解码器获得与查询时刻相关的潜状态，同时避免生成完整网格。

3.4 传感器 token 与混合融合

每个传感器输入包含位置、采样时刻和测值。两层 MLP 把三元组投影到 64 维，并加入可学习的传感器类型嵌入：

\[ T_s^{(i)}=\operatorname{MLP}([x_i,t_s,u_i])+e_{\mathrm{sensor}}. \]

传感器 token 在上下文 Transformer 之前与场 token、潜变量 token 拼接：

\[ C=\Phi_{\mathrm{context}}\left([T_f;T_{z_0};T_s]\right). \]

上下文编码器包含 3 层、4 个注意力头、宽度 64。查询解码器随后对 (C) 做注意力。因此，实现既不是早期叙事中的理想预融合，也不是严格晚期融合，而是早期 token 拼接加后期查询注意力。

这个区别直接影响解释。把模型称为“晚期融合”会掩盖传感器 token 已进入上下文编码器；称为“早期融合”又会掩盖解码器注意力路径。更准确的名称是混合 token 融合。

3.5 查询解码器

给定查询坐标 ((x,t))，解码器构造

\[ q(x,t)=\operatorname{MLP}\left[ \gamma(x,t),\,z(t),\,u_0^{\mathrm{local}}(x) \right], \]

其中 (\gamma) 包含 Fourier 坐标特征，(u_0^{\mathrm{local}}) 包含局部场特征。查询通过交叉注意力读取上下文：

\[ \tilde{q}(x,t)=\operatorname{Attn}(q,C,C), \qquad \hat{u}(x,t)=\operatorname{Head}\left(\operatorname{FFN}(\tilde{q})\right). \]

上下文与查询数量解耦，因此评测可以分块处理任意数量的时空坐标。保留评测使用每块 4,096 个查询。

4 训练与评价协议

4.1 严格周期平移增强

空间域是周期的。对任意精确解 (u(x,t))，平移后的场

\[ u_\delta(x,t)=u(x-\delta,t) \]

仍然是同一方程、边界条件和黏性系数下的精确解。因此，该增强只改变空间位置覆盖，不改变物理。

生成脚本从 1,408 条轨迹开始，为每条轨迹额外生成两份完整时空场的随机整数循环平移，位移取 ({1,\ldots,255})。最终每条原始轨迹对应 3 份样本，总数为 4,224。随机数生成器固定，并保存平移量与副本编号元数据。

与任意幅度缩放或频谱扰动相比，周期平移不会制造非解样本，因此证据更强。但它只适用于周期问题。

4.2 目标函数

训练目标包含采样点数据损失、初始条件损失、周期边界损失和可选 PDE 残差项。保留的核心运行使用

\[ \mathcal{L} =\mathcal{L}_{\mathrm{data}} +\mathcal{L}_{\mathrm{IC}} +\mathcal{L}_{\mathrm{BC}} +\lambda_{\mathrm{PDE}}\mathcal{L}_{\mathrm{PDE}}, \qquad \lambda_{\mathrm{PDE}}=0. \]

保留运行的优化目标关闭 PDE 项。验证分数仍使用非零诊断权重：

\[ s_{\mathrm{dev}} =L_2^{\mathrm{dev}} +0.1\,\mathrm{PDE}_{\mathrm{RMS}}^{\mathrm{dev}}. \]

启用损失平衡。残差诊断使用名义黏性系数 0.01，而数据实际覆盖多个黏性值。由于 PDE 项在优化中关闭，这不会改变训练目标，但进一步说明残差只能作为粗略的项目内部诊断。更准确的描述是“带物理诊断项的数据驱动算子”，而不是完整的物理信息优化器。

4.4 指标

相对 L2 在整个 (256\times101) 场上计算，再对测试轨迹取平均：

\[ L_2^{\mathrm{rel}} =\frac{1}{M}\sum_{m=1}^{M} \frac{\lVert\hat{u}_m-u_m\rVert_2} {\lVert u_m\rVert_2}. \]

PDE 残差在 128 个随机时空查询上通过自动微分计算并取均方根。两个细节限制了解释：查询坐标在评测时随机采样，且残差对所有样本使用名义黏性系数 0.01，而数据覆盖多个黏性值。因此该残差是粗略的项目内部诊断量，不是跨论文标准基准。后续实验应固定并保存评测查询集，并使用每个样本对应的黏性系数。

5.1 保存配置

审计检查以下两条运行：

  • experiments/outputs_burgers_dataset/custom_v11_multimodal_sensors8_24k
  • experiments/outputs_burgers_dataset/custom_v12_multimodal_prefusion_24k

6.2 PDE 残差没有一致改善

平移运行没有一致降低 PDE 残差：

平均残差上升约 9.3%，而 L2 误差下降。这是一个有用的负观察。严格平移增强了位置覆盖和场精度，但在当前诊断协议下不保证更低残差。

差异可能来自多个因素：优化目标不包含 PDE 项，残差在随机坐标采样，检查点由组合验证分数选择。因此，不能把结果表述为“增强提升物理一致性”。

6.3 传感器融合初步结果

一个 seed 11 的初步比较在同样的 1,408 条训练配方上加入 8 个传感器，采样时刻为 (t_s=0.5)。参数量从 336,546 增加到 341,026。

测试相对 L2 0.097000 0.115319
测试 PDE RMS 0.838240 1.038709
参数量 336,546 341,026

传感器运行在两个记录指标上都更差。这是初步负结果，不是严格融合结论：只有单个种子，传感器运行增加参数，而且损失函数没有跨模态对齐项。它仍然说明“加入信息量更多的测量”不会自动改善算子。

一个合理解释是传感器分支可能利用固定位置或单一时采样时刻形成捷径。场路径已经包含初始条件，传感器 token 只有在优化目标明确要求跨模态一致性时才会产生稳定收益。仅拼接 token 不会自动创造这种对齐。

7 缺失融合研究的可复现协议

7.1 明确研究问题

下一轮实验应检验一个可证伪问题：

在数据、参数预算、优化预算、评测查询和检查点规则匹配的条件下，独立实现的预融合模型是否与当前混合 token 融合模型在预测误差和 PDE 残差的联合分布上存在差异？

问题不应预设某一方胜出。区间重叠或结果不确定同样具有科学价值。

7.2 必需实现

至少比较四类系统：

  1. 纯场基线。
  2. 使用共享联合编码器的早期特征融合。
  3. 使用模态专用编码器的表征级注意力融合。
  4. 当前混合 token 融合。

每个实现都需要独立单元测试前向路径。测试应覆盖 token 数量、张量形状、梯度流，以及纯场路径中不存在传感器信息泄漏。

7.3 架构指纹

每次运行至少保存：

  • 融合模式和实现标识；
  • 模块类列表；
  • 参数量；
  • 参数形状哈希；
  • 源代码哈希或提交号；
  • 完整训练目标和实际损失权重调度；
  • 数据划分哈希；
  • 检查点选择规则；
  • 评测查询种子。

目录名称本身不足以证明来源。

7.4 实验矩阵

因素 最低设置
传感器数量 0、4、8、16
采样时刻 0.2、0.5、0.8
随机种子 至少 5 个配对种子
预算 匹配步数，并单独设置匹配实际耗时组
损失 固定主权重，并报告敏感性分析
指标 相对 L2、固定查询 PDE RMS、逐时刻误差、谱误差
报告 均值、标准差、配对差异、bootstrap 区间

只有架构指纹和纯场控制通过后，才应运行完整传感器矩阵。

7.5 多模态对齐目标

直接拼接不足以保证有效融合。一个最小对齐目标是

\[ \mathcal{L}_{\mathrm{align}} =\sum_i\lVert\hat{u}(x_i,t_s)-u_i\rVert^2 +\lVert\hat{u}_{\mathrm{field+sensor}} -\hat{u}_{\mathrm{field-only}}\rVert^2. \]

第一项要求场预测解释测点，第二项鼓励两条路径在应当一致的区域给出一致预测。训练时应使用模态丢弃，保证纯场路径仍然是有效回退。

8 局限性

本文有六方面限制。

第一，只评价一个 PDE、一个空间分辨率和一个边界条件。数据覆盖五个黏性系数，而不是单一系数。周期平移只对周期场严格成立，不能直接迁移到非周期问题。

第二，正面增强结果使用三个配对随机种子。这足以说明当前基准上的重复改善，但不足以估计总体效应或支持小效应显著性结论。

第三，PDE 残差使用随机查询和名义黏性系数诊断，其平均值与场误差变化方向相反。后续评测应保存固定查询集，使用样本对应的真实系数，并报告残差定义和归一化。

第四，传感器分支只测试一个种子，且没有对齐损失。负结果具有工程警示价值，但不是最终融合比较。

第五，存档融合运行缺少独立预融合实现和源代码提交。数值差异可以作为历史观察，但不能作为因果证据。

第六，模型不是数值求解器的工程替代。保留配置约 33.7 万参数，在现有硬件上训练约 47 至 52 分钟。它是用于受控算子学习实验的研究原型。

9 结论

本文把多模态算子项目已经证明的内容与仅仅提出过的内容分开。

已证明的是一条严格周期平移增强效应。三个配对运行的平均测试相对 L2 改善 6.09%，三个种子全部改善；增强精确保持 PDE 不变，因此可以较清楚地解释为位置覆盖收益。PDE 残差没有一致改善，所以结论应限定为精度与数据覆盖。

多模态收益尚未得到证明。直接传感器 token 在保留试验中增加误差，早期交叉注意力与预融合对比也无法归因，因为保存的配置和参数签名不能识别两套独立机制。下一步不应继续更换架构标签，而应保存可执行架构指纹，使用配对随机种子、固定评测查询和跨模态对齐目标。

更一般的启示是：当控制方程已知时，精确对称性可以提供可靠的数据增强；增加一种模态并不自动带来更好的算子。在多模态科学机器学习中，模态交互的证据必须和架构图一样明确。
